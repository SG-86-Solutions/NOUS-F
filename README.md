# NOUS-F-MIP: Memory Injection Proxy

A local port-based proxy utility for attaching external memory databases to LLM interactions. It provides a persistent, lightweight retrieval system and a self-state updating mechanism to maintain conversational relevance across sessions.

## 📂 Project Structure
All core server files, python orchestration loops, and setup instructions live directly inside the **`NOUS-F-MIP`** folder. 

Open that directory to view the configuration guides and setup parameters for the proxy pipeline.
